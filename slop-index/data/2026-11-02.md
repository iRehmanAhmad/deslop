## Method

Each launch site (page + up to 5 same-origin stylesheets) is scanned with the deslop engine; Slop Score = min(100, fails*12 + warns*4); verdicts 0–15 Clean, 16–45 Mild, 46+ Heavy Slop; top twin = highest Visual Twins similarity against the built-in 10-archetype corpus.

Scores grade the page's *source* (HTML + same-origin CSS), not a screenshot, and they measure template tells, not whether AI was actually used. A launch built by hand in the default style will score like one built by a bot, and vice versa. Full per-launch data, including the Visual Twins fingerprints: `2026-11-02.json` next to this file.

One more reading note: when a launch's URL is a page on a big platform — a GitHub repository page is the common case — the grade describes that platform's page furniture, not the maker's own design. Read those rows as platform scores.
