# deslop

**Your AI agent's UI looks like every other AI agent's UI.**

Inter on everything. A purple-to-blue gradient hero. Pillowy 32px cards
floating on giant soft shadows. Glassmorphism. Emoji bullets. "Supercharge
your workflow — seamlessly." It is the PowerPoint-2003 of this decade: not
bad exactly, just instantly recognisable as *generated by a machine that was
not thinking about your product*.

**deslop** is a zero-dependency scanner plus an agent skill that catches
those patterns in your source files and reports them — with the file, the
line, and how to fix it — *before* the agent calls the UI done.

## No code? Check any live site in the browser

**[deslop-checker.rehmanahmad.com](https://deslop-checker.rehmanahmad.com)** —
paste a published site's URL and get a **Slop Score** (0 = clean, 100 =
every AI cliché), each tell explained in plain language, and a **copy-paste
fix prompt** for every finding that you hand back to Lovable, Bolt, v0 or
whichever AI builder made the site. Built for site owners, not developers;
the Worker lives in [`web-checker/`](web-checker/) and runs this same rule
engine.

## Client audit reports

Freelancers and agencies: turn a scan into the document you actually hand
to a client.

```bash
node bin/deslop.js report ./src --out audit.html --client "Acme Ltd" --site "acme.com"
node bin/deslop.js report https://acme.com --out audit.html
```

[`report`](bin/deslop-report.js) scans a local file/folder or fetches a
live URL (the page plus its same-origin stylesheets, with the same SSRF
guards as the web checker) and writes a **single self-contained HTML
report**: cover header, the Slop Score (same formula as the web checker),
an executive summary in plain language, every finding grouped must-fix
first — what it means, where it was found, and the recommended fix — an
RTL note when Urdu/Arabic issues are present, and a "what good looks like"
closing section with a soft service call-to-action. It prints cleanly to
PDF. The wording is the web checker's plain-language copy, not a second
hand-maintained copy: `web-checker/worker.js` is the source of truth and
`bin/report-copy.js` is generated from it by
[`web-checker/sync-copy.js`](web-checker/sync-copy.js), so a rule reads
identically in the browser checker and in a client report.

Sample, generated from `fixtures/sloppy.html` (score 100, Heavy Slop):
[`examples/sample-audit-report.html`](examples/sample-audit-report.html) —
download it and open it in a browser.

## Visual Twins

Most AI-built pages are not just slop in the details — they are the *same
page* underneath: same hero → logos → features → pricing → FAQ → CTA
skeleton, same palette, same font, same pillowy corners. **Visual Twins**
fingerprints that template DNA and tells you whose layout yours is a twin
of.

```bash
node bin/deslop.js twins https://your-site.com
node bin/deslop.js twins page.html --corpus ./my-fingerprints --json
```

The fingerprint is computed from **source** — the fetched HTML plus its
same-origin stylesheets, or a local HTML file plus its local stylesheets
— and captures five signals: the DOM skeleton (landmark tags in order,
their counts, a nesting-depth profile, hashed to a short id), the ordered
**section pattern** (hero, logos, features-grid, testimonials, pricing,
faq, cta, footer — detected with simple documented heuristics), the top-6
**palette**, the **font** set, and the **radius/shadow** signature.
Similarity is a weighted blend: section pattern 40%, palette 25%, fonts
15%, structure 20% (the skeleton blended with radius/shadows).

Targets are compared against a built-in corpus of ten page archetypes
(hand-authored fixtures in [`twins-corpus/`](twins-corpus/), fingerprinted
by the tool itself — regenerate with `node twins-corpus/build-corpus.js`).
With `--corpus <dir>`, every fingerprint JSON in your folder joins the
comparison, so a corpus of real collected pages (a launch index, a client
list) can plug straight in. The demo in
[`examples/`](examples/twins-demo-clone.html) — a SaaS landing written for
this repo — scores **88%** against the "Generic SaaS landing (Tailwind
default)" archetype, while a plain CV page tops out at **21%** against
every archetype. Assertions live in
[`tests/twins.test.js`](tests/twins.test.js).

**Honest limits:** this is a source-signature comparison, not a
screenshot diff and not ML. Two pages can share a fingerprint and still
differ in detail, and a page whose styles are generated entirely at
runtime by a JS framework will fingerprint thinner than it renders. Read
the score as "how much of the same template DNA", not "how identical it
looks".

## SlopBench + Slop Index

Claims about detecting "the AI look" are cheap; deslop publishes its test
set and its launch grades so the claims can be checked.

**[SlopBench](slopbench/)** is a public, provenance-labelled benchmark:
30 single-file pages — 15 written in the idiom an AI builder ships by
default, 15 written with deliberate, non-template design decisions —
graded by the deslop engine. First run (2026-11-02, full detail in
[`slopbench/RESULTS.md`](slopbench/RESULTS.md)):

- Mean Slop Score: **AI 33.1 vs human 2.9** (medians 20 vs 0).
- **80% accuracy** at the best separating threshold (score ≥ 8) — and the
  failures are named, as they will be in every published run: false
  positives are a hand-coded 1997 homepage (12), an Art Deco hotel page
  (8) and a punk gig flyer (8); false negatives are the cream + serif
  agency archetype, the default docs site and the minimal portfolio
  (all 0 — the current default is quieter than the rules).
- The dataset is detector-agnostic: `slopbench/labels.json` is the
  contract, and the protocol for grading another tool on it is in
  `slopbench/README.md`. Week 1, n = 30, every page authored or selected
  in-repo — the caveats are printed in RESULTS.md, not footnoted away.

**[The Slop Index](slop-index/)** runs the same machinery over the real
world: the newest ~20 Show HN launches each run, fetched live, scored,
fingerprinted, and snapshotted into `slop-index/data/`. First snapshot
(2026-11-02): **20 launches found, 19 scored, average Slop Score 31.6**;
sloppiest a word-game launch at 100, cleanest a Linux syscall reference
at 0; one launch refused the fetch (HTTP 403) and is recorded as a
failure, not skipped. Weekly runs turn the snapshots into a trend — and
their fingerprints into a corpus of real-world layout twins.

## What it catches

40 rules: 5 `fail` (Inter as the only font, purple-to-blue gradients in CSS
or Tailwind, lorem ipsum shipped to production, an RTL page with no
`dir="rtl"`) and 35 `warn` (gradient
text, glassmorphism, giant radii and shadows, emoji in the UI, checkmark
feature lists, "Welcome to" heroes, "Get Started" buttons, "Trusted by
10,000+ happy customers", em-dash overuse, div soup, `transition: all`,
focus outlines deleted with no replacement, and more).

Every rule is documented — why it reads as AI slop and how to fix it — in
[docs/RULES.md](docs/RULES.md).

## The RTL pack — the blind spot every other scanner has

**deslop is the first anti-slop scanner that can read RTL.** The whole
Western anti-slop canon assumes your page is left-to-right and
Latin-script. Point those tools at an Urdu or Arabic page and they see
nothing — while the agent that generated it shipped a page with no
`dir="rtl"`, Urdu set in a Latin display font's fallback, margins and
arrows that never flipped, and `11/02/2026` baked into Arabic sentences.

The RTL pack (9 rules, in
[docs/RULES.md](docs/RULES.md#rtl-pack--urdu--arabic-right-to-left))
catches exactly that: missing `dir`, Latin-only fonts on Arabic script,
Urdu set in Naskh with no Nastaliq, forced `text-align: left`, physical
left/right properties, backwards gradients, un-mirrored icons, and
hard-coded Latin dates. It activates automatically on any file containing
Arabic-script text, `lang="ur"`/`lang="ar"`, `dir="rtl"` or
`direction: rtl` — no flag, no config — and stays silent everywhere else.
Try it: `fixtures/rtl-sloppy.html` (1 fail, 7 warnings) vs
`fixtures/rtl-clean.html` (0 findings).

## Example

Real output, from running deslop on the deliberately awful sample in
[`fixtures/sloppy.html`](fixtures/sloppy.html) (the clean sample,
`fixtures/clean.html`, scores 0 findings):

```text
$ node bin/deslop.js fixtures/sloppy.html

sloppy.html:8  [FAIL] inter-only-font — Inter is the only named font in the stack — the default AI typeface
    fix: Choose a typeface with a point of view (a serif display, a grotesque with character) and pair it deliberately.
sloppy.html:12  [FAIL] purple-blue-gradient — Purple/violet-to-blue linear gradient — the default AI hero look
    fix: Pick a colour story from the brand or the content; a solid colour or a duotone photo beats the default gradient.
sloppy.html:17  [warn] gradient-text — Gradient text (background-clip: text) — a signature AI landing-page move
    fix: Set the headline in one strong colour. Emphasis comes from weight and size, not a rainbow fill.
sloppy.html:22  [warn] giant-border-radius — Border radius of 24px or more — everything-pillowy AI card look
    fix: Tie radius to a small scale (4/8/12px). Big radii are for avatars and pills, not every card.
sloppy.html:45  [warn] welcome-hero — 'Welcome to …' hero heading — the most generic headline an agent can write
    fix: Lead with what the visitor gets or does here, not a greeting.
sloppy.html:47  [FAIL] tailwind-purple-gradient — Tailwind gradient from violet/indigo/purple/fuchsia — instant AI-template signal
    fix: Use a solid brand colour, a subtle same-hue tint, or a real image instead.
sloppy.html:55  [FAIL] lorem-ipsum — Lorem ipsum placeholder text left in the UI
    fix: Write real copy, or mark the block as a draft and finish it before shipping.

deslop: scanned 1 file(s) — 5 fail, 34 warning(s)
```

## Install & usage

No dependencies, nothing to install — just Node.js 18 or newer.

```bash
git clone https://github.com/iRehmanAhmad/deslop
cd deslop

node bin/deslop.js ./src              # scan a folder (defaults to ./src, else cwd)
node bin/deslop.js path/to/file.tsx   # scan one file
node bin/deslop.js ./src --format json
```

Scans `.css`, `.scss`, `.html`, `.jsx`, `.tsx`, `.vue`, `.astro` and
`.svelte` files. Exit code is **1 when any `fail` rule hits**, 0 otherwise —
so it drops straight into a CI step or a pre-commit check:

```bash
node bin/deslop.js ./src || echo "AI slop detected — fix before merging"
```

## Use it as an agent skill (the real point)

The scanner alone is a lint. The leverage is [`SKILL.md`](SKILL.md): an
agent skill for Claude Code, Cursor, Codex and compatible agents that makes
the agent

1. run deslop after every UI change, **before** declaring the work done,
2. fix every `fail`, and fix or explicitly justify every `warn`,
3. write new UI to the anti-slop principles in the first place (typography
   with a point of view, colour as a decision, one depth story, specific
   copy, semantic structure).

Copy `SKILL.md` (and keep `bin/deslop.js` reachable, or point it at this
repo) into your agent's skills folder, and your agent starts grading its
own homework.

## A note on intent

deslop does not exist to flatten deliberate design. If a project's brand
genuinely *is* a violet gradient, that finding gets a one-line justification,
not a redesign. The target is the **unchosen default** — the patterns an
agent reaches for when it is not thinking. Chosen design is design; defaults
are slop.
