Introduction

Parcel is a small routing library. This page explains what it does and when to use it.

Installation

npm install parcel-router

Requires Node 18 or newer.

Basic usage

Define a route with parcel.get() and start the server:

parcel.get("/", (req, res) => res.send("ok"));
