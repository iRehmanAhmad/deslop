# SlopBench — a public benchmark for AI-design-slop detectors

**SlopBench is a small, labelled, public dataset for grading tools that claim to
detect the "AI-built look"** — including deslop itself. It exists because every
detector in this space (deslop included) ships with impressive claims and no
shared test. Here, the failures are published next to the scores.

## What's in the folder

| File | What it is |
|---|---|
| `labels.json` | The contract: 30 pages, each with a ground-truth label (`ai` / `human`), its provenance (`fixture`, `archetype`, `authored`) and a note on the design idiom it represents. |
| `pages/` | The 30 pages themselves — single self-contained HTML files, inline CSS, no build step. |
| `run.js` | The harness. Scans every page with the deslop engine, computes Slop Scores, finds the best separating threshold, and reports accuracy **with the false positives and false negatives named**. |
| `RESULTS.md` | Generated by `run.js`. Headline numbers, per-page scores, the FP/FN lists, the method, and the caveats. Regenerated on every run — never edited by hand. |

## Run it

```bash
node slopbench/run.js          # console table + regenerate RESULTS.md
node slopbench/run.js --json   # machine-readable results
```

## Grade your own detector

The dataset is detector-agnostic: `labels.json` is the only contract.
`RESULTS.md` documents the protocol (score every page as-is, try every
threshold, publish your false positives and false negatives by name, state the
dataset version). **A benchmark whose failures are visible is worth more than
a leaderboard whose are not.**

## Honest limits (week 1)

- **30 pages, all authored or selected by the deslop maintainer** (the
  `fixture`/`archetype` pages are copied verbatim from this repo's own test
  material). No page is a capture of a real production site; labels record the
  design idiom a page represents. That circularity is stated, not hidden —
  growing the set with independently sourced pages is the roadmap.
- Single-file pages only: inline CSS, no external stylesheets or frameworks.
- A score measures template tells, not authorship. See the caveats in
  `RESULTS.md` before quoting any number.
